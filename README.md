# MiruRecetas · Acceso web

**MiruRecetas** es una web y aplicación instalable (PWA) de recetas, menús semanales, información nutricional, organización del cocinado y listas de compra.

- **Dirección principal:** https://mirurecetas.github.io/
- **Aplicación:** https://mirurecetas.github.io/menu-anual-recetas/

Esta dirección raíz redirige a la aplicación y conserva los parámetros y fragmentos de los enlaces compatibles. También ofrece un enlace de acceso cuando JavaScript no está disponible.

Este repositorio público contiene únicamente la página de acceso y su descripción. No aloja fuentes de desarrollo, manuales internos ni datos privados.
